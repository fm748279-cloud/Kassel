# كاسب لقطع الغيار — kassep.com

منصة لبيع قطع الغيار الجديدة والمستعملة والتشليح، فيها:

- **الموقع** (`index.html`): بحث بالسيارة ورقم القطعة، صفحة لكل قطعة بالصور، سلة طلب، و"اطلب قطعة غير موجودة"، مع إرسال الطلبات على واتساب.
- **لوحة الإدارة** (`admin.html`): إضافة القطع بالصور من الجوال، ومتابعة الطلبات وطلبات القطع.
- **قاعدة البيانات** (`schema.sql`): على Supabase (مجانية في البداية).

قبل ربط قاعدة البيانات يشتغل الموقع **بوضع تجريبي** فيه بيانات للعرض.

---

## خطوات الإطلاق

### ١. تفعيل الموقع على GitHub Pages
1. في المستودع: **Settings** ← **Pages**
2. تحت **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**
3. في خانة **Custom domain** اكتب `kassep.com` واضغط **Save**

### ٢. ربط الدومين من GoDaddy
في GoDaddy: **Domain** ← **kassep.com** ← **DNS**، ثم:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | fm748279-cloud.github.io |

احذف أي سجل **A** قديم للاسم `@`، وأي توجيه (Forwarding) مفعّل على الدومين.
بعد ما يشتغل الدومين (من دقائق إلى ساعات)، فعّل **Enforce HTTPS** من صفحة Pages.

### ٣. قاعدة البيانات (Supabase)
1. أنشئ حساب على supabase.com، ثم **New project** (اختر أقرب منطقة، مثل Frankfurt أو Mumbai)
2. افتح **SQL Editor** ← **New query**، والصق محتوى `schema.sql` كاملاً، واضغط **Run**
3. من **Authentication** ← **Users** ← **Add user** أنشئ حسابك (بريد وكلمة مرور)
4. ارجع لـ **SQL Editor** وشغّل هذا مع وضع بريدك:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'بريدك@example.com';
   ```
5. من **Project Settings** ← **API** انسخ **Project URL** و **anon public key**

### ٤. الإعدادات
افتح `config.js` وعبّ:
- `supabaseUrl` و `supabaseAnonKey` من الخطوة السابقة
- `whatsapp`: رقم واتساب كاسب بصيغة `9665xxxxxxxx`

بعدها تدخل لوحة الإدارة من **kassep.com/admin.html** بحسابك وتبدأ تضيف القطع.

## ملاحظات
- مفتاح `anon` آمن للنشر في الموقع، والحماية عن طريق صلاحيات قاعدة البيانات: الزوار يقرأون القطع المعروضة ويرسلون طلبات فقط، والمشرف وحده يعدّل.
- لا تنشر أبداً مفتاح `service_role`.
- الصور تتصغّر تلقائياً قبل الرفع لتسريع الموقع.
